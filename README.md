Reflection

How can I ensure that my code, program, or software is functional and secure?
I make sure my code works and is secure by testing every requirement and validating all inputs before they are used. I also check for edge cases, use clear error messages, and make sure no sensitive information is hard-coded. Running unit tests often helps confirm that new changes don’t break anything that was already working.

How do I interpret user needs and incorporate them into a program?
I start by breaking down user needs into specific, testable requirements. For example, if a user needs a 10-digit phone number, I write a test to confirm that any other input fails. I focus on keeping the design simple while still meeting what the user actually asked for.

How do I approach designing software?
When designing software, I focus on organization and simplicity. I separate the logic into smaller parts so it’s easier to test and maintain. I use clear names, short methods, and validation checks that prevent problems early. My goal is always to make the program easy to understand, easy to test, and reliable in different situations.
